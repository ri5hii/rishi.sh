rishi.sh
Repository: github.com/ri5hii/rishi.sh
Portfolio: rishi.sh

Interactive terminal-driven portfolio — not a website, a command-line interface.

Users interact by typing commands into a simulated terminal that responds with
rich output: profile data, project details, blog entries, system info.

Scope:
+- command-driven navigation with flag parsing and autocomplete
+- rich HTML output formatting inside terminal frames
+- dual-mode architecture: terminal + switch UI

Goal:
Deliver high-signal personal identity through interaction, not pages.

Tech Stack

  • Astro (static-first, island architecture)
  • TypeScript
  • Tailwind CSS v4
  • Bun
  • Vanilla JS (no framework islands)
  • Vercel (deployment)

Commands

  • - whoami → profile card with avatar
  • - neofetch → ASCII art + system info
  • - about → skills, background, links
  • - projects → live GitHub repos + project sheets
  • - blog → process/outcomes cards
  • - contact → email, LinkedIn, GitHub
  • - resume → opens PDF
  • - help → per-command docs with flags/examples

Terminal UX

  • ArrowUp/Down command history navigation
  • Tab autocomplete with ghost preview
  • Boot animation with character-by-character typing
  • Session expansion on first command
  • Ctrl/Cmd+I to focus prompt
  • Mobile responsive with compact layout
  • ASCII banner glitch animation

Dual-Mode Architecture

  • Terminal Mode (/ and /terminal):
    • - Interactive CLI portfolio
    • - Full command engine with dispatch
  • Switch UI Mode (/switch/*):
    • - Traditional multi-page layout
    • - Nav tabs: Home, Projects, Blog, Resources, About, Contact
    • - Terminus font, separate styling system
  • Toggle button between modes in both headers

Content Architecture

  • GitHub API integration for live repo data
  • Project sheets as static HTML with manifest mapping
  • Local blog posts with structured rendering
  • About page as standalone HTML fragment
  • HTML sanitization before DOM injection

Versioning

  • v0.1 — terminal shell, basic commands
  • v0.2 — command hardening, autocomplete, history
  • v0.3 — responsive output, content architecture
  • v0.4 — switch UI skeleton (in progress)

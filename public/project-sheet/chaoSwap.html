ChaoSwap
Repository: github.com/ri5hii/ChaoSwap

Terminal chess variant with a chaos swap mechanic

ChaoSwap layers a "Chaos Swap" rule onto standard chess: each turn, a player
can make a normal move OR let the engine randomly swap two of their own pieces.
Built as a learning project exploring game engine design and terminal UI in Go.

The project focuses on correct chess rule enforcement and a clean,
interactive terminal experience.

Design goal:
+- faithful chess rule implementation
+- deterministic chaos swap selection
+- responsive, keyboard-driven TUI

Core Features

  • Full chess engine with castling, en passant, promotion, and draw detection
  • Chaos swap mode — engine randomly swaps two friendly pieces
  • Swap legality checking with 5-rule validation
  • Interactive TUI with board rendering and move log
  • Undo support for both normal moves and chaos swaps

Tech Stack

  • Go
  • Bubble Tea (TUI framework)
  • Lipgloss (terminal styling)

Chaos Swap Rules

  • Must swap two friendly pieces of different types
  • King cannot swap from its home file or leave check
  • Pawns cannot swap to the back or promotion rank
  • Swapped pieces must have different legal move counts
  • Castling rights revoked if a rook leaves its corner square

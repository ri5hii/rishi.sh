Peony
Repository: github.com/ri5hii/Peony

A calm, CLI-first cognitive holding space for unfinished thoughts

Peony is a local-first system designed for ideas that are not ready to become
tasks, notes, or decisions. Instead of forcing structure, it allows thoughts
to exist in a natural lifecycle: capture → rest → resurface → evolve or release.

"Some thoughts don't need solving. They need somewhere safe to wait."

Built for clarity, reflection, and psychological safety, not productivity.

Philosophy

  • - Thoughts are seeds, not obligations
  • - They may rest, mature, transform, or dissolve
  • - No deadlines, no reminders, no urgency loops
  • - Language is soft — no streaks, no metrics, no guilt
  • - Private by default: no accounts, no sync, no analytics

Cognitive Model

  • Core unit: Thought
  • Represents:
    • - unresolved decisions
    • - early ideas
    • - lingering worries
    • - memory fragments
  • Contains:
    • - lifecycle state (6 states)
    • - temporal context (eligibility_at)
    • - optional emotional metadata (valence, energy)
    • - interaction history (event log)

Lifecycle

  • - Captured → Resting → Tended
  • - → Evolved / Released / Archived
  • Time-aware resurfacing via configurable SettleDuration
  • Default settle: 18 hours between tending sessions
  • Append-only event log tracks every state transition

CLI Commands

  • - add → capture a new thought
  • - tend → surface thoughts ready for reflection
  • - view → paginated list with state filters
  • - evolve → externalize into a task/note
  • - release → permanently delete with reindexing
  • - config → editor and settle duration settings
  • Editor integration opens $VISUAL / $EDITOR for tending

Tech Stack

  • Go
  • SQLite (modernc.org/sqlite, pure-Go)
  • Hand-rolled CLI dispatcher
  • External editor integration

Storage

  • Single SQLite file (~/.local/share/peony/peony.db)
  • Schema versioning with transactional migrations
  • ID reindexing on release for dense numbering

Versioning

  • v0.4 — tend notification polish, merge cleanup
